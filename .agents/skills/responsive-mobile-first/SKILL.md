# Responsive & Mobile-First Skill

1. **Mobile First Approach**: Structure layout classes starting from mobile views (`w-full flex-col`), expanding gracefully on larger screens (`md:flex-row md:grid-cols-3`).
2. **Touch-Friendly UI**: Ensure tap targets (buttons, links, inputs) have adequate spacing and minimum recommended dimensions for mobile fingers.
3. **Theme & Dark Mode Ready**: Write Tailwind CSS classes structured for dark mode toggles (`dark:bg-slate-900 dark:text-white`).
