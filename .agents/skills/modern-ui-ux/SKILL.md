# Modern UI/UX Guidelines

1. **Visual Aesthetics**: Use subtle gradients, modern soft drop shadows (`shadow-xl shadow-slate-200/50`), rounded borders (`rounded-2xl`), and glassmorphism where appropriate (`backdrop-blur-md bg-white/80`).
2. **Typography & Hierarchy**: Ensure strong typographic contrast, clean font scaling, and tight tracking (`tracking-tight`) for bold headings.
3. **Color Harmony**: Use sleek neutral base tones (Slate/Zinc) paired with bold primary accent colors (Indigo, Violet, Emerald, or Cyan).
4. **Micro-Interactions**: Always include subtle, smooth hover and click feedback (`transition-all duration-300 hover:-translate-y-1 hover:shadow-2xl active:scale-95`).
