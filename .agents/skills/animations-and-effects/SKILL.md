# Animations & Visual Effects Skill

1. **CSS & Keyframes**: Utilize keyframe animations, glowing gradient borders, floating background elements, and smooth fade-in reveal effects.
2. **Canvas & 3D Interactivity**: When requested for canvas or 3D visual components, write clean, performance-optimized JavaScript canvas loops (always properly requestAnimationFrame and handle window resizes).
3. **Smooth UI Dynamics**: Ensure dropdowns, modals, and sidebar drawer menus open with smooth opacity and scale transitions.
